One funny line for make.fun's "The One-Line Laugh" bounty ($5 in USDC):

> My smartwatch congratulated me on 10,000 steps, most of them earned pacing in front of the microwave.

A single sentence (101 characters), an everyday truth with a surprise ending.

## Run it

```sh
node main.ts
```

This writes the line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), with no trailing newline. Running it twice produces the same file both times.
